# 중고 상품 공통 JSON 스키마

스키마 버전은 `1.0.0`이다. 세 플랫폼 중 공개 구조화 데이터가 가장
풍부한 N플리마켓을 기준으로 작성했으며, 다른 플랫폼이 제공하지 않는
필드는 값을 추정하지 않고 `null`로 저장한다.

## 최상위 구조

```json
{
  "schemaVersion": "1.0.0",
  "query": "에어팟 프로3",
  "sort": "latest",
  "collectedAt": "2026-08-19T00:00:00+00:00",
  "count": 20,
  "failedCount": 0,
  "products": [],
  "errors": []
}
```

## 주요 상품 필드

- `productName`: 플랫폼이 별도로 제공하는 표준 상품명
- `catalogProductId`: 가격 비교 등에 사용하는 카탈로그 상품 ID
- `attributes`: 플랫폼이 제공하는 상품 사양 목록
- `package`: 정품 박스와 보증 정보
- `trade.shipping`: 택배 가능 여부, 배송비, 부담 주체, 도서산간 추가금,
  플랫폼이 제공하는 배송 방식 목록
- `trade.inPerson`: 직거래 가능 여부와 공개 지역 목록
- `metrics`: 찜, 조회, 채팅 수
- `seller`: 공개 판매자명과 후기·거래 요약
- `source`: 광고, 구매 인증, 다른 마켓 동시 등록 정보

`trade.inPerson.locations`에는 공개된 행정동이나 거래 지역만 저장한다.
판매자의 실제 발송 주소나 구매자의 배송지는 수집하지 않는다. 설명에
자유 형식으로 적힌 역·학교·편의점 등의 문장은 `description`에 보존하지만,
확실한 구조화 데이터가 아니므로 위치 필드로 추정하지 않는다.
